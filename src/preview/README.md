# 记录首页动效预览

本地入口 `/record-home-preview.html`，九个默认头像对比入口 `/record-home-preview.html?view=avatars`。
已确认的首页组件已移入 `src/components/record-home/`，正式入口与本地预览共用。此预览入口和九头像校准页仍不加入生产构建。

- 脑袋尺寸为上一版宽高的 75%，右侧操作泡泡避开耳朵。
- 叹号和问号从头像右上方的共同起点依次沿扇形向外弹出；“换个说法”的尖角朝左上，指向头像。
- 加号线宽加倍，在进入应用时转四圈，用 2.4 秒由快到慢停回正向，按钮本身不转。连续 10 秒没有点击或按键后再转一次，每段闲置只提醒一次；再次操作后重新计时。弹窗打开、页面不可见或启用减少动态效果时暂停。
- `useAvatarMotion.js` 控制叹号、问号、想法云与眼睛方向。组间留白，弹窗打开或页面不可见时停止；系统减少动态效果时停用。
- 点击头像重播头像与气泡入场和表情循环。鼠标停下 1.6 秒后恢复自动眼神；触屏使用自动动作。
- `avatar-eye-rigs.json` 分别定义九个默认头像的 18 个眼白轮廓、瞳孔比例与颜色。坐标以 `avatarTemplate()` 生成的 256 × 256 裁切为准；修改裁切或更换头像素材后必须重新校准。
- `AnimatedAvatar.jsx` 使用独立的 SVG 眼白、瞳孔及高光图层。眼白覆盖底图旧瞳孔，瞳孔移动限制在对应眼部轮廓中。头部只有小幅平面歪动。
- 眼睛动画支持九个默认头像。自定义头像保留原图，不套用默认头像的眼睛坐标。
- 欢迎文案使用本地句库轮换，不调用文字或生图服务。
